01
The surface

Handover is a product
surface, not a vibe.

In the first week of March 2026, the Cursor bill for Steller’s pivot moved from execution into hardening. Built From the Rubble prices that week at $118 and calls it the agent protocol layer. The sentence in the essay names four files: AGENTS.md, QWEN_PROTOCOL.md, HANDOVER_TO_QWEN.md, and CHANGELOG_AI.md. It also names what that layer was for: guardrails, confirmation gates, session protocols, canonical port maps. The system, the essay says, became legible to machines.

The following week, March 9–14, is the $96 stabilisation week. Spend dropped. The essay says the system no longer needed the heavy architectural sessions, because Qwen could operate it from the docs. Bede, the Zain Sudan digital wallet, entered staging. That is the published picture of a handover: a named operator, a drop in session cost, and a first partner moving into staging.

A handover protocol is the surface the next agent meets. If the surface is only a chat transcript, the next session starts from zero. The rubble essay’s eighth rule says this directly: CHANGELOG_AI.md is the memory one agent passes to the next. Without it, every session starts from zero. Qwen Coder is described as the operator that reads AGENTS.md, runs tests before done, and logs what it changed.

Those sentences are the protocol as published. They are not the files.

A plausible session script, a sample changelog entry, or a step list “in the spirit of” those files would be an invented document with a real filename on it.

03
Principles only

What the essays
already committed to.

The principles of a handover are the eight rules in the rubble essay, not a private runbook. Keep the golden flow in one file. Name things so they can be grepped — the essay lists PlaceBambooOrderJob, ReconciliationJob, and SendWebhookJob as examples of searchable names. I am not describing those last two jobs; the essay only establishes that their names are greppable. Write AGENTS.md before the code. Make the wrong move unambiguously wrong. Use one deploy command, docker compose up -d. Treat docs as the codebase that gets read. Require test output before done. Log the change so the next agent is not blind.

The scorecard adds the operating claim that sits next to handover: once the docs exist, Qwen operates on about $5–15 a day. Expected daily Cursor and Qwen spend after the pivot, for routine operations, was about $15. A 95.2% cache hit rate is the published reason documentation compounds. Files written once are read across sessions. That is an economic fact about handover, not a description of a missing file’s table of contents.

The Complete Story draws the line the protocol has to respect. The AI did not rescue the platform. The architectural redesign made the platform rescuable by AI. A handover document that claims the model saved a microservices system the agents could not see would contradict the published account. What was handed over was a fat-controller path, Hangfire jobs with names, and a file that says where to start.

04
Continuity

The loop that still
runs without those files.

Closed-loop CI is the continuity mechanism that does not depend on the missing protocol bodies. The root AGENTS.md says to use gh workflow run, gh workflow list, and gh workflow view. Never push directly to main. The path is feature branch, tests, pull request, auto staging. Production is manual and needs a human. The backend file repeats the ban on pushing to main, keeps dotnet build at zero errors, forbids deleting or recreating model, migration, or context files, and tells the agent to fix tests only in test files.

The smoke after a config change is a business check, not a status-code check: POST /api/orders returns 202, then poll until Completed. A health gate comes before that smoke. Verify the business outcome, not only HTTP 200. Environment variables use a double underscore. Those rules are how one session leaves the system in a state the next session can trust, even when CHANGELOG_AI.md is not available to quote.

Logging still matters. The essay says Qwen logs what it changed, and it names CHANGELOG_AI.md as that memory. I can require the behavior — a next session must be able to see what changed — without inventing the file’s format, headings, or retention. If the log is somewhere else now, that location is not in the record this essay is allowed to use.

Writing without inventing. Describe the rule, the command, and the published outcome. When the source is a filename without a body, say the body is missing. Do not fill the gap with a template.
05
Open questions

What a careful
handover still does not know.

These questions stay open because answering them would invent a fact.

  • What QWEN_PROTOCOL.md required of a session — gates, ports, tone, stop conditions — beyond the essay’s phrase “guardrails, confirmation gates, session protocols, canonical port maps.”
  • What HANDOVER_TO_QWEN.md listed as already done, still risky, or out of bounds.
  • Whether CHANGELOG_AI.md is still the log Qwen writes, or only the name the March essay used.
  • The day-by-day rebuild inside each weekly spend bucket. The published buckets are the $207 reckoning, the $163 execution, the $118 hardening, and the $96 stabilisation. Finer diary entries are not published.
  • Anything about a second host that could not be searched. Absence there is not evidence the files lived somewhere else.

Bede’s commercial terms are in the same category. The published fact is a first live integration: Bede, the digital wallet of Zain Sudan, moved from staging into an active API integration, and the platform’s stated partner path reaches a first successful API transaction in under sixty seconds. Terms, volumes, and revenue are not in this handover.

The practical protocol, stated only from what can be checked, is short. Read the root router. Obey the backend locks. Do not push main. Show the test run and the 202-to-Completed smoke. Leave a log the next agent can read. Do not pretend a missing file has been quoted. That is less romantic than a four-document protocol layer. It is the handover the record supports.
